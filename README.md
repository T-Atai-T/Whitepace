# Whitepace

## 📌 **Описание проекта**  
Whitepace — это адаптивный лендинг, сверстанный по макету из Figma. Проект демонстрирует современные подходы к вёрстке с использованием Flexbox и media-запросов, а также включает взаимодействие с пользователем через простые JavaScript-скрипты.

## 🎨 **Что включает в себя проект**  
Проект включает в себя:

- Полностью адаптивную вёрстку для различных устройств.
- Поддержку современных браузеров.
- Интерактивное бургер-меню, написанное на чистом JavaScript.
- Использование svg-графики для декоративных элементов.

## 🗂 **Структура проекта**  
- `index.html` — основной HTML-файл, содержащий структуру страницы.
- `style.css` — стили проекта.
- `responsive.css` — стили для адаптивности через media-запросы.
- `script.js` — скрипт для открытия/закрытия бургер-меню.
- `images/` — папка со всеми изображениями и svg-иконками, используемыми в макете.

## ⚙️ **Основные функции**  
1. **Адаптивный интерфейс:**
   - Страница корректно отображается на любых устройствах: от мобильных телефонов до больших экранов.
   - Используются media-запросы для изменения отображения контента.

2. **Базовое бургер-меню:**
   - Реализовано с использованием чистого JavaScript.
   - При нажатии переключает классы для отображения/скрытия меню и кнопок.

3. **Семантическая и чистая вёрстка:**
   - Код написан с соблюдением HTML5-стандартов.
   - Простой и читаемый CSS.
